# MC2 city assets

Generated by `mc2_inventory.py`. Source: `$MC2_PC_ASSETS/..`

## The finding that matters

**Almost the entire MC2 city is plain text, meshes included.** Only the AI
paths (`.aib`) and the baked vertex colours (`.pvc`, `.cpvs`) are binary.

This is the opposite of the MC:LA PSP port, which was binary on both ends
and stalled on a vertex encoding that was never reversed. Here the
vertices are decimal numbers on lines beginning with `v`, so the reading
side of a port is a parser, not a reverse-engineering problem.

## Formats

| ext | files | kind | what it is |
|---|---|---|---|
| `xmod` | 5469 | texto | the MESH. verts/normals/colors/tex1s/materials/primitives, then `v x y z` lines |
| `cc` | 2482 | texto | per-component: inst_cpv, bounding sphere, and which LODs exist |
| `pdef` | 374 | texto | prop definition: name, LOD list, bounding sphere |
| `mm` | 352 | texto | same shape as pdef, used for breakable pieces |
| `hood` | 31 | texto | a neighbourhood: unique components (name + AABB) and their instances |
| `gt` | 28 | texto | lighting: ambient colour and friends |
| `txt` | 8 | texto | build logs left in the shipped data (exported / finished / xbox) |
| `aib` | 5 | binario | AI paths. Header TSV1 |
| `algt` | 4 | texto | area light types |
| `inf` | 4 | texto | flat list, `group : index name` - component to something mapping |
| `lvl` | 4 | texto | the city: hood count, world extents, grid dimensions, hood names |
| `prop` | 4 | texto | placed props |
| `pvc` | 4 | binario | per-vertex colours for the base condition |
| `sndref` | 4 | texto | named sound regions with bounds |
| `occlude` | 3 | texto | occlusion volumes |

## How it fits together

```
losangeles.lvl        numhoods, extents, grid dimensions, hood names
  l_downtown.hood     unique_component N { name, emin, emax } + instances
    <name>.xmod       the mesh, as text
    <name>.cc         LODs present, bounding sphere, inst_cpv
  losangeles.prop     placed props, each defined by a .pdef
  losangeles.pvc      baked vertex colours          [binary]
  losangeles.aib      AI paths                      [binary]

city/<name>/<time>_<weather>/*_cpvs.dat
                      baked lighting, 9 per city    [binary]
```
